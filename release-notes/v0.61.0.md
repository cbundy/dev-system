## New

- **One command stands up the factory database** - `factory-db-bootstrap` now also creates a `<db>_migrator` role, generates every login role's password and writes the writer, reader and migrator URL files itself (`--secrets-dir`, `--migrator-dir`). A new `--migrate` mode applies new migrations as the migrator alone, so a schema upgrade no longer needs the admin URL. ([#1044](https://github.com/cbundy/dev-system/pull/1044))
- **Factory database migrations stay expand-only** - `npm run lint` refuses a migration that would break a workspace on an older image (drops, renames, type changes, new required columns or constraints), naming the file and line. ([#1042](https://github.com/cbundy/dev-system/pull/1042))

## Fixed

- **A build or fix step waits for its stop gate** - The loop no longer ends a gated writer's step, and reuses its slot for review, while the stop gate is still running; it waits for the settling gate line, bounded by the gate timeouts. ([#1045](https://github.com/cbundy/dev-system/pull/1045))
- **A capped wind-down cannot start new work as the workspace stops** - The Coder stop script now keeps the wind-down request in place, and the workspace start clears it, so the loop starts nothing in the seconds before the container stops. ([#1046](https://github.com/cbundy/dev-system/pull/1046))
- **A newly waiting issue gets a release review within the hour** - When an issue starts waiting on a release after the hour's review, the judge reviews again for it instead of waiting for the next hour. ([#1049](https://github.com/cbundy/dev-system/pull/1049))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.49.0.
- Factory database: no new migration. To add the migrator role and the URL files, re-run the bootstrap command in docs/factory-db.md (step 3) with `--secrets-dir` and `--migrator-dir`; restart the workspaces if its summary reports new passwords.
- Coder template: push the updated `dev-system` template so the workspace start clears a wind-down request.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- On base image 2.49.0, run `factory-db-bootstrap` with `--secrets-dir` and `--migrator-dir` against a test database and confirm it writes three 0600 URL files and a second run changes nothing.
- Run `factory-db-bootstrap --migrate` with the migrator URL file and confirm it prints the schema version before and after, and refuses the admin URL.
- Add a migration with a `DROP COLUMN` and confirm `npm run lint` names its file and line.
- Decline a fix in a gated repo and confirm the decision log shows the step held until its gate line, then ended after its gate-pass.
- After a Coder stop that hits the wind-down cap, confirm no agent step or slot starts after the stop, and the restarted loop is not winding down.
- Make an issue start waiting on a release after the hour's review and confirm a release review runs with the reason naming it.
