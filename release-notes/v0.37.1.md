## Fixed

- **Treehouse installs no longer hit GitHub's API rate limit** - Environment setup and the base image now download treehouse straight from its latest release instead of asking GitHub's API first, so installs and image builds no longer fail with a 403 when many run at once. ([#585](https://github.com/cbundy/dev-system/pull/585))
- **One GitHub login shared by every workspace** - Workspaces on the same Docker host now share one GitHub sign-in, so a new sign-in no longer silently revokes an older workspace's token (GitHub keeps only 10 per user). ([#597](https://github.com/cbundy/dev-system/pull/597))
- **Orchestrator (loop) template pushes again** - Its description is now within Coder's 128-character limit, and the push script rejects an over-long description before pushing anything. ([#580](https://github.com/cbundy/dev-system/pull/580))

## Upgrade

- Base image: rebuild or re-pull the dev container to get base image 2.31.1.
- Coder: push every template from main (`coder/push.sh <template>`), update each workspace, then sign in to GitHub once from any updated workspace to seed the shared login.
