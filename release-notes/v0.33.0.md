## New

- **PRs that only fell behind main merge without a full re-run** - The orchestrator can now rebase a PR that is just behind main, prove its changes are identical to what already passed the pipeline, and merge once CI is green. Conflicts or any difference still trigger a full re-gate. ([#499](https://github.com/cbundy/dev-system/pull/499))

## Fixed

- **Plugins follow the release pin** - A repo that declares the plugin marketplace without a ref now picks up the image's release pin instead of staying on an old plugin version. Moving a marketplace keeps your installed plugins, and leftover installs from deleted worktrees are cleaned up and no longer listed. ([#494](https://github.com/cbundy/dev-system/pull/494))
- **Factory HUD counts are accurate** - Expired design claims no longer show as active design work, and issues closed on GitHub are now reliably marked closed in the factory. ([#493](https://github.com/cbundy/dev-system/pull/493))
- **Split issues keep moving** - When the designer splits a ready issue, the new sub-issues are marked ready automatically, so work continues without waiting on the owner. ([#490](https://github.com/cbundy/dev-system/pull/490))
- **Faster PR linkage checks** - Checking and repairing PR-to-issue links is noticeably quicker. ([#485](https://github.com/cbundy/dev-system/pull/485))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image: the plugin pin and linkage fixes ship in the base image; rebuild or re-pull the dev container to get them.
