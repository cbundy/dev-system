## New

- **The factory loop logs release tags and milestone changes** - For a repo with a `Next release` milestone, the loop now records each new release tag once (as cut by its own release task or by the workflow) and records each change in the milestone's state, so release history and holds show up in the factory data. ([#1117](https://github.com/cbundy/dev-system/pull/1117))

## Fixed

- **No repeat release reviews while a release is running** - After the judge starts a release, the loop no longer wakes it every hour or for each issue waiting on a tag. The quiet period ends when the new tag appears or after the new `releaseInProgress` setting (default 2h, 0 turns it off, shown in `/factory config`). ([#1116](https://github.com/cbundy/dev-system/pull/1116))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

- In a repo with a `Next release` milestone, confirm a new tag writes exactly one `released` event with the right source.
