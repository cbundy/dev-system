## New

- **Factory loop records its regime** - A new loop setting `regime` (`factory_loop_v2` by default, or `testbed`) is passed as `FACTORY_REGIME`, with the loop's session id, to every command the loop runs, so the events it writes carry the regime and the loop session. It shows in the Loop group of `/factory config`. ([#1195](https://github.com/cbundy/dev-system/pull/1195))
- **Factory reports split by regime** - `callum-flow-evaluate` takes `--regime <factory_loop_v2|testbed|manual|unknown>` to report on one regime, and without it adds per-regime throughput and spend breakdowns. Token spend is attributed to a regime through each session. ([#1196](https://github.com/cbundy/dev-system/pull/1196))
- **Saved factory queries per regime** - The metrics guide gains a rule for reading any saved query per regime, three new grouped queries (merges per device and per day, and tokens per merged issue, by regime), and the hand-recorded rescue example now uses `--regime manual`. The `query-factory-data` skill explains the per-regime reading. ([#1197](https://github.com/cbundy/dev-system/pull/1197))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image: rebuild or re-pull the dev container to get the updated `callum-flow-evaluate`.

## Verify

- Run `/factory config` and confirm the Loop group shows `regime` as `factory_loop_v2` by default; confirm `/factory config set regime manual` is refused.
- After a loop pass, confirm new events written by the loop carry `regime` and the loop's `session_id`.
- Run `callum-flow-evaluate --regime testbed` and confirm `window.regime` reads `testbed`; run it with a bad value and confirm it exits 2.
- Run `callum-flow-evaluate` without `--regime` and confirm `throughput.by_regime` and `spend.by_regime` appear and `spend.by_regime` sums to `spend.rows`.
- Run the documented rescue command with `--regime manual` and confirm the row carries `regime = manual`.
