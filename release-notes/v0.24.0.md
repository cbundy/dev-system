## New
- **Trusted-author reads** - every factory script, agent and skill now reads issues, comments and PRs only through `callum-flow-issue-read`, so text from anyone outside `CALLUM_FLOW_TRUSTED_AUTHORS` never reaches an agent, a claim, a brief or the merge guard ([#332](https://github.com/cbundy/dev-system/pull/332), [#330](https://github.com/cbundy/dev-system/pull/330)).
- **Test-weakening warning** - the merge guard warns when a pipeline fix commit deletes or weakens a test, and each case is logged and counted in `callum-flow-evaluate` ([#333](https://github.com/cbundy/dev-system/pull/333)).
- **Design routing** - `callum-flow-design-route` decides per issue whether design goes to a live session or a sub-agent, with `design:session` and `design:subagent` label overrides ([#329](https://github.com/cbundy/dev-system/pull/329)).

## Fixed
- **Workspace parameters** - `dev-restart-self --parameter name=value` applies Coder parameter changes reliably and checks they took; `--fresh` starts one new conversation without turning resume off ([#327](https://github.com/cbundy/dev-system/pull/327)).
- **Image CI rate limits** - image workflows log in to Docker Hub, so CI no longer fails on anonymous pull limits ([#331](https://github.com/cbundy/dev-system/pull/331)).

## Upgrade
- Plugin: run `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image 2.22.0: rebuild or re-pull the dev container (Coder: update the workspace). Set `CALLUM_FLOW_TRUSTED_AUTHORS` first, or the factory scripts refuse to read issues.
