## Changed

- **No more Co-Authored-By trailers on agent commits** - The settings template turns off the harness's commit attribution, and `callum-dev update` applies it even over a repo's own commit attribution. The implementation skill forbids agent attribution trailers, and the adjudicators treat a pipeline that aborts after rewriting its own commit as an environment failure that needs a fresh run. ([#631](https://github.com/cbundy/dev-system/pull/631))
- **Releases ship without waiting for owner approval** - The release process picks the version and image level, validates the notes, ships, and reports the tag, release URL and workflow results afterwards. The factory loop's judge follows each repo's own release process and only waits for the owner where that process requires approval. ([#634](https://github.com/cbundy/dev-system/pull/634))

## Fixed

- **Factory loop agents no longer hang on shell commands** - Every loop role is told to use commands that exit, bound exploration with a timeout, and never leave watchers or background waits behind. ([#616](https://github.com/cbundy/dev-system/pull/616))
- **Resuming an escalation that needs changes sends a fixer** - With an owner note, or a verdict that is not an environment failure, a resume now sends a fixer with the instructions instead of re-running the same code. ([#622](https://github.com/cbundy/dev-system/pull/622))
- **Dropped issues give their worktree back** - A finished, dropped issue's clean, idle worktree returns to the pool. ([#623](https://github.com/cbundy/dev-system/pull/623))
- **Sub-agents cannot write into the main checkout** - A guard hook refuses a sub-agent's edits and shell writes into the main checkout in repos that use treehouse, and points it at its worktree. ([#629](https://github.com/cbundy/dev-system/pull/629))
- **Rebased PRs no longer move to a new branch** - After the loop rebases a PR, the merge guard passes when the build machine's working copy only lags or predates the rebase, so the PR merges instead of being replaced. Ship the plugin together with base image 2.32.2. ([#630](https://github.com/cbundy/dev-system/pull/630))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.32.2, together with the plugin update.
- Plugin, CLI and templates: `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.
