## Breaking

- **The skills-based orchestrator is retired** - The `issue-orchestrator` and `implement-issue` skills, the five callum-flow agents (designer, explorer, implementer, fixer, adjudicator) and the `orchestrator` Coder template are gone; `coder/push.sh orchestrator` now refuses. The factory loop is the only orchestrator, and the manual path is a person working in a worktree, running the canonical commands and opening a plain PR that links its issue. Synced CLAUDE.md files drop the no-mistakes and orchestrator wording. ([#1312](https://github.com/cbundy/dev-system/pull/1312))
- **The factory state report speaks only state names** - `callum-flow-factory-state` rows no longer carry `stage`, `entered_at`, `run` or `v2`, and `minutes_in_stage` is now `minutes_in_state`; the text tables show the state. The loop, HUD and reconcile tool read the state only, so update the plugin and the image together. ([#1307](https://github.com/cbundy/dev-system/pull/1307))

## New

- **Merge tool can check a tested tree** - `callum-flow-merge-guard --patch --tested-tree <sha>` and `callum-flow-merge --tested-tree` merge only when merging the PR onto its base gives exactly the tree that was tested, groundwork for a merge train. Merged events record the train, its drop reason, the tested tree and whether it matched (migration 0034), and CI also runs on `factory-train/**` pushes. ([#1313](https://github.com/cbundy/dev-system/pull/1313))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A loop workspace on the `orchestrator-loop` template picks up the plugin only after that template is pushed at this release (`coder/push.sh orchestrator-loop`).
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update` (brings the CLAUDE.md wording without the orchestrator skills).
- Base image: rebuild or re-pull the dev container to get image 2.74.0. Its factory DB moves to migration 0034, which a loop start applies.
- Coder: once no workspace uses it, delete the retired `orchestrator` template.
