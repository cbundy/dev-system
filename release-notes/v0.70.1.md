## Changed

- **Release holds record their reason** - When the release judge holds or fails a release, the loop now writes its one-line reason into the loop note, so the factory data shows why each release waited. ([#1118](https://github.com/cbundy/dev-system/pull/1118))

## Fixed

- **Queued stop gates no longer die at 10 minutes** - A gate waiting behind another gate was cut off exactly 10 minutes after its stop hook began. The loop now raises the agent stall limit to cover the gate's wait and run time, and a gate that is still cut off records how long it waited and ran. ([#1120](https://github.com/cbundy/dev-system/pull/1120))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- With `gateConcurrency` set, queue two writers' stop gates and confirm the second passes after waiting longer than 10 minutes in total.
- Confirm a held release task writes a `reason=` token on its loop note and `loop_entry.decision_reason` carries it.
