## New

- **Merge size and hand merges in the factory data** - Every recorded merge now carries the PR's changed files, additions and deletions. The sweep also logs PRs merged to main that no factory event recorded, so hand merges show up in the data. `docs/metrics.md` has queries for them. ([#1185](https://github.com/cbundy/dev-system/pull/1185))

## Changed

- **Queue merges no longer hold up a pass** - The factory loop's merge queue now merges in the background with a time bound, like the sweep and heartbeat. A loop restart for an update waits until a running merge finishes. ([#1186](https://github.com/cbundy/dev-system/pull/1186))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image: rebuild or re-pull the dev container to get the updated merge and sweep tools.

## Verify

- Merge a PR through the loop and confirm its `merged` row in `factory.event_log` has `files`, `additions` and `deletions`.
- Merge a PR by hand, wait over an hour, run the sweep and confirm it logs one `merged` event for it (actor sweep, recovered) and no duplicate on a second run.
- Watch a loop pass while a queue merge runs and confirm the merge shows as running off the pass and the pass is not held.
- With an update due during a running merge, confirm the restart waits with `update due: waiting on` naming the merge.
