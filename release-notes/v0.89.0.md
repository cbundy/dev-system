- **The loop no longer tells you when the main checkout fast-forwards** - The main-checkout tripwire stays quiet when the checkout moves by a plain fast-forward to origin on the default branch, such as the hourly upgrade. Local commits, branch switches and new tracked files still raise a notice. ([#1240](https://github.com/cbundy/dev-system/pull/1240))
- **A testbed loop checks PR links with its own tools** - When the workspace file sets `toolsDir`, the merge guard and the link fixer use that checkout's PR-link check instead of the image's copy. ([#1241](https://github.com/cbundy/dev-system/pull/1241))
