## New

- **Loop agents never hang on a permission prompt** - When a factory loop agent hits a permission prompt that nobody is watching, the loop now denies it at once with a reason that tells the agent how to work around it or end its step, and logs a `prompt_denied` factory event. Before, the agent waited forever. ([#708](https://github.com/cbundy/dev-system/pull/708))
- **A per-minute pass summary in the factory data** - In act mode the loop sends one event per minute with how many passes ran, their duration (mean, p50, p90, max) and how many acted or failed, so slow or stalled loops show up in the data. ([#706](https://github.com/cbundy/dev-system/pull/706))

## Fixed

- **Loop workspaces pick up the template's plugin version on restart** - A loop workspace no longer stays on the plugin version its checkout last pinned: the Orchestrator (loop) template's version now wins, and `dev-doctor` fails when the installed version differs from the one wanted. ([#704](https://github.com/cbundy/dev-system/pull/704))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.36.0.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Coder: push the Orchestrator (loop) template from main (`coder/push.sh orchestrator-loop`), then update loop workspaces.
