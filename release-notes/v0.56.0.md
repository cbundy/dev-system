## New

- **Repo line fields as factory database columns** - The event fields the plant console reads (state changes, PR, round, timings, model, verdicts and outcomes) are now columns of `factory.event_log`, so readers query them directly instead of digging into each event's payload (migration 0008). ([#959](https://github.com/cbundy/dev-system/pull/959))
- **Opt-in Coder CLI login** - A workspace that drives other workspaces can turn on the new `coder_login` parameter to get a logged-in `coder` CLI on every start, from a token the host keeps outside Terraform. It is off by default. ([#953](https://github.com/cbundy/dev-system/pull/953))
- **Split trackers close themselves** - When the last sub-issue of a split closes, the factory loop closes the parent tracker with a comment listing its sub-issues, so it no longer blocks the issues that waited on it. ([#954](https://github.com/cbundy/dev-system/pull/954))
- **Hold a PR out of the merge queue** - Put the `don't-merge` label on an issue or its PR and the factory loop neither updates nor merges it until the label is removed, while the rest of the queue keeps merging; the title shows `held <n>`. ([#965](https://github.com/cbundy/dev-system/pull/965))

## Changed

- **Factory tools read the new event store by default** - The claim tools, `callum-flow-factory-state`, `callum-flow-evaluate`, `heartbeat-state` and the factory HUD now answer from the new event store. `--source old` (or the tool's `..._SOURCE=old` variable) is the way back, and `shadow` is opt-in. ([#951](https://github.com/cbundy/dev-system/pull/951), [#955](https://github.com/cbundy/dev-system/pull/955))
- **One factory loop spec and a trimmed decision log** - The v1 spec is gone: v2 SPEC section 13 now describes the foundation as built, `DECISIONS.md` holds only the decisions in force, and a test fails on any spec or decision cite that does not resolve. ([#949](https://github.com/cbundy/dev-system/pull/949), [#960](https://github.com/cbundy/dev-system/pull/960))

## Fixed

- **dev-login no longer leaks its internal variables** - `DL_WATCH`, `DL_STATES` and `DL_CACHED` are no longer inherited from the caller or exported into the tmux servers a login starts. ([#950](https://github.com/cbundy/dev-system/pull/950))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.47.0.
- Factory database: after the restart `dev-doctor` reports the factory database as behind until `factory-db-bootstrap --db <name>` is re-run with the admin URL (migration 0008).
- Coder template: the owner pushes the updated `dev-system` template; the Coder CLI login stays off until a workspace sets `coder_login` and the host token directory exists.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

- Label a ready-to-merge issue `don't-merge` and confirm the loop holds it while the next PR merges, then remove it and confirm it merges.
- Merge the last open sub-issue of a split and confirm the loop closes the parent with a comment and no closing keyword.
