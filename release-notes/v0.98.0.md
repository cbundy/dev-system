## New

- **Per-device GitHub API health** - Each device's heartbeat now reports its remaining REST and GraphQL rate limit, their reset times, and how many GitHub API errors the factory loop on that device hit in the last hour. Values are empty where a device cannot report them, such as no GitHub login or no loop running. ([#1337](https://github.com/cbundy/dev-system/pull/1337))
- **Orchestrator token spend in the minute summary** - The loop's once-a-minute summary now records the tokens its own orchestrator session spent that minute, so the orchestrator's cost shows up next to the agents' cost. ([#1333](https://github.com/cbundy/dev-system/pull/1333))
- **Usage throttle tier in the minute summary** - The minute summary now records which usage tier the loop acted on (normal, slow, stop-new or stop-all) and whether an owner override held it at normal. ([#1338](https://github.com/cbundy/dev-system/pull/1338))
- **What-if API cost per agent step** - Each ended agent step and intake stamp now records what it would have cost at Anthropic's public API prices, priced per model including nested agents. This is an estimate, not a bill; steps on an unknown model are left unpriced and logged. `docs/metrics.md` has queries for cost per merged issue and per model. ([#1339](https://github.com/cbundy/dev-system/pull/1339))

## Fixed

- **`callum-dev update` keeps filled-in text on template rewords** - When a template only rewords a placeholder the repo already filled in, or removes a repo-owned section the repo already filled in, update now keeps the repo's text and prints a `kept` line instead of reporting a conflict. Other conflicts are reported as before. ([#1330](https://github.com/cbundy/dev-system/pull/1330))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A loop workspace on the `orchestrator-loop` template picks up the plugin only after that template is pushed at this release (`coder/push.sh orchestrator-loop`).
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image: rebuild or re-pull the dev container to get image 2.77.0. The factory database gains three expand-only migrations, which the loop applies at its next start.

- Confirm a `loop_passes` event from a running loop carries session token counts and `usage_tier`.
