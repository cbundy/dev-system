## New

- **A read-only panel role for a public factory dashboard** - The factory DB bootstrap now creates a `NAME_panel` login that can read only the repos on a public allowlist and write nothing, managed with `factory-db-bootstrap --panel-dir` and `--public-repo add|remove OWNER/NAME`. ([#1266](https://github.com/cbundy/dev-system/pull/1266))

## Upgrade

- Base image: rebuild or re-pull the dev container to get image 2.71.0 (factory DB migration 0030 and the panel role in `factory-db-bootstrap`). Loops apply the migration at their next start. To create the panel role and its URL, run `factory-db-bootstrap` once with the admin URL and `--panel-dir DIR` on the dashboard host.

## Verify

- On the new image, confirm a loop start migrates the factory DB to schema version 30.
- Run `factory-db-bootstrap` with `--panel-dir` and confirm the summary names the panel role and the URL file is written mode 0600.
- Add a repo with `--public-repo add OWNER/NAME`, connect with the panel URL and confirm only that repo's rows are visible in `factory_public.event_log`.
- Confirm the panel role cannot insert into or read any `factory` base table.
