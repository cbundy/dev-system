## New

- **What-if cost of the loop's own work** - The loop's minute summary and each ended task or tell wake now record what the loop's own judgement work would have cost at Anthropic's public API prices. This is an estimate, not a bill; work on an unknown model is left unpriced. `docs/metrics.md` has queries per repo and day and per wake. ([#1341](https://github.com/cbundy/dev-system/pull/1341))
- **Subscription usage readings name the login and carry the what-if total** - A usage reading taken under a subscription login now says so and carries the loop's running what-if dollar total for the month, with the date it restarts. When the total is missing, the reading says why. ([#1348](https://github.com/cbundy/dev-system/pull/1348))
- **`dev-restart-self --check`** - A check-only mode answers whether this workspace could restart itself, naming where the Coder token comes from, without sending any request. `dev-doctor` runs it in a Coder workspace and warns, with a fix, when no Coder token is present. ([#1347](https://github.com/cbundy/dev-system/pull/1347))

## Changed

- **`/factory update` refuses when the workspace cannot restart itself** - The command now checks the workspace's Coder credentials first and refuses at once, changing nothing, when a restart could never run. The refusal is logged. On an image without the check it accepts as before and says the credentials went unchecked. ([#1350](https://github.com/cbundy/dev-system/pull/1350))

## Fixed

- **`dev-restart-self --dry-run` no longer pretends to succeed without a token** - It now fails with the same "no Coder session token" message a real run gives. ([#1347](https://github.com/cbundy/dev-system/pull/1347))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A loop workspace on the `orchestrator-loop` template picks up the plugin only after that template is pushed at this release (`coder/push.sh orchestrator-loop`).
- Base image: rebuild or re-pull the dev container to get image 2.78.0, which brings `dev-restart-self --check`, the `dev-doctor` token warning and the new usage reading fields.

## Verify

- Confirm a `loop_passes` event from a running loop carries `cost_usd`, and an ended task or tell `loop_entry` event carries `cost_usd`.
- On a subscription login, confirm a `usage` event carries the subscription auth and the what-if total with its reset date.
- On the new image in a Coder workspace with a token, confirm `dev-restart-self --check` exits 0 and names the token source, and `dev-doctor` prints an OK line for it.
- In a Coder workspace without a token, confirm `dev-restart-self --check` exits 1 and `dev-doctor` warns with the `coder_login` fix.
- In a workspace without a Coder token on the new image, confirm `/factory update <reason>` answers `Not changed` and writes nothing.
- Confirm `dev-restart-self --dry-run` without a token exits 1.
