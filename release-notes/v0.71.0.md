## New

- **CI jobs GitHub refused to start are held, not failed** - When GitHub will not start a CI job because the account's payments failed or its spending limit is reached, the loop now holds the PR instead of spending re-runs and fix rounds on it. It tells the owner once (`actions-refused`), probes one refused run every 30 minutes, and when jobs start again sends `actions-resumed` and re-runs each refused run once. ([#1129](https://github.com/cbundy/dev-system/pull/1129))
- **API-key spend can be recorded** - The usage event and `factory.event_log` gain optional spend fields (auth, spend, budget and its reset time, migration 0019), and docs/metrics.md has two queries for spend per day against the budget and time in each budget tier. Nothing writes these readings yet. ([#1130](https://github.com/cbundy/dev-system/pull/1130))

## Changed

- **Transition events accept a conflicts count** - `transition.v1` gains an optional `conflicts` count and the old-log translator reads a `conflicts=` token, ready for the record rebuild. Nothing writes it yet. ([#1135](https://github.com/cbundy/dev-system/pull/1135))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.55.0. A loop workspace with the migrator secret applies migration 0019 itself at start-up.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
