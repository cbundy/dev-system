## New
- **Factory state at a glance** - `callum-flow-factory-state` and the `factory-state` skill show where every issue stands (queued, designing, implementing, in pipeline, parked, ready to merge, merged, closed without merge) and flag stuck work, from the event log and live GitHub ([#369](https://github.com/cbundy/dev-system/pull/369)).

## Changed
- **Raw GitHub reads blocked** - a new hook and settings deny list stop agents reading issue, PR and comment text directly; the deny message names the trusted reader (`callum-flow-issue-read`). Writes such as comments, edits and merges still work, and `callum-dev update` now merges deny lists as well as allow lists ([#371](https://github.com/cbundy/dev-system/pull/371)).

## Upgrade
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update` (brings the new deny list into `.claude/settings.json`).
- Base image 2.25.0: rebuild or re-pull the dev container (Coder: restart the workspace).
