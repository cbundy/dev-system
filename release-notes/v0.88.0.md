## New

- **Factory reports show issue size, overlap and merges by kind** - `callum-flow-evaluate` gains `size` and `overlap` sections and a per-day split of merges to main into factory, hand and unlinked, and the factory metrics docs and `query-factory-data` skill gain matching saved queries for issue size, overlap with in-flight work and the hottest files. ([#1234](https://github.com/cbundy/dev-system/pull/1234))

## Fixed

- **A stray heartbeat from the loop's own workspace no longer holds the loop** - A beat written under another device name from the same Coder workspace is now treated as a twin instead of a second orchestrator, so it no longer keeps the loop out of act mode or raises a heartbeat warning. `heartbeat-loop` now names its device from `DEV_MACHINE_NAME` first. ([#1228](https://github.com/cbundy/dev-system/pull/1228))
- **A review that hits a merge conflict hands one fixer both problems** - When a PR goes dirty while its reviewer is still running, the loop waits for the review and then sends a single fixer the conflict plus the review findings. A step the loop stopped itself is now logged as `stopped` rather than `agent-dead`. ([#1233](https://github.com/cbundy/dev-system/pull/1233))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image: rebuild or re-pull the dev container to get image 2.69.0.
