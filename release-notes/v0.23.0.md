## New
- **dev-query** - a read-only way for agents to query the central factory database, with the connection URL kept out of argv, env and output ([#299](https://github.com/cbundy/dev-system/pull/299)).
- **query-factory-data skill** - agents answer questions about latency, gates, fix rounds and token spend from factory data, with the caveats that go with each number ([#302](https://github.com/cbundy/dev-system/pull/302)).
- **Stale container warning** - at session start the agent is told when its image is stale or missing tools, and a "command not found" for a factory tool explains the rebuild fix; `dev-doctor` warns too ([#308](https://github.com/cbundy/dev-system/pull/308)).
- **Trusted-author reader** - `callum-flow-issue-read` returns only issues and comments by the authors in `CALLUM_FLOW_TRUSTED_AUTHORS`, which the Coder and devcontainer templates now set; nothing enforces it yet ([#313](https://github.com/cbundy/dev-system/pull/313)).
- **Curated release notes** - every release now publishes notes like these with upgrade steps ([#301](https://github.com/cbundy/dev-system/pull/301)).

## Fixed
- **Missing /persist directories** - existing workspaces now get new persistent directories (such as the factory event log) created at start instead of silently losing data ([#303](https://github.com/cbundy/dev-system/pull/303)).
- **PR linkage repair** - `callum-flow-fix-linkage` no longer edits the pipeline's protected PR appendix, which broke the next pipeline run ([#304](https://github.com/cbundy/dev-system/pull/304)).

## Upgrade
- Plugin: run `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`. Desktop dev containers: export `CALLUM_FLOW_TRUSTED_AUTHORS=<login>:<numeric id>` on the host before rebuilding.
- Base image 2.18.0: rebuild or re-pull the dev container (Coder: update the workspace) to get `dev-query`, the trusted-author reader and the `/persist` fix.
