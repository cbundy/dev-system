## Fixed

- **Loop token counts are complete right after a restart** - The loop's own orchestrator token counts are no longer empty for the first minute after a loop restart, so token totals over a window that spans a release or restart are complete. A resumed session counts only what came after the loop started, so nothing is counted twice. ([#1370](https://github.com/cbundy/dev-system/pull/1370))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A loop workspace on the `orchestrator-loop` template picks up the plugin only after that template is pushed at this release (`coder/push.sh orchestrator-loop`).
