## New

- **A workspace can use its own factory database** - A factory database URL placed in a workspace's own secrets folder now overrides the shared one for that workspace only, so one workspace can point at a test database without touching the others. A broken override fails instead of falling back to the shared database. The Coder template mounts the folder whenever `workspace_secrets_dir` is set. ([#793](https://github.com/cbundy/dev-system/pull/793))
- **Write a factory event directly by type** - `callum-flow-event --type T --data JSON` writes one event in the new format, checked against its schema, straight to the new event log. ([#796](https://github.com/cbundy/dev-system/pull/796), [#805](https://github.com/cbundy/dev-system/pull/805))

## Fixed

- **Factory database bootstrap works as the default user** - `factory-db-bootstrap` no longer fails with "migrations directory not found" when run as the image's default user. ([#807](https://github.com/cbundy/dev-system/pull/807))
- **Clearer token check when GitHub rate-limits** - `dev-doctor` now says the rate limit was reached instead of reporting GitHub unreachable. ([#803](https://github.com/cbundy/dev-system/pull/803))
- **Release timing follows the configured cadence** - The judge aims to ship merged work within the repo's minimum release cadence instead of a fixed 6 hours. ([#790](https://github.com/cbundy/dev-system/pull/790))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.41.0.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Coder: push the templates from main (`coder/push.sh <template>`) to mount each workspace's secrets folder whenever `workspace_secrets_dir` is set.
