## Fixed

- **No hook error on every shell command** - v0.30.0 and v0.31.0 registered a `forbid-broad-kill` hook whose script was not part of the release, so every Bash call in a session could report a hook error. The registration is removed until the hook itself ships ([#459](https://github.com/cbundy/dev-system/pull/459))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- `plugins/callum-flow/hooks/hooks.json` at v0.31.1 lists only hooks whose scripts exist
- A Bash call in a session on v0.31.1 shows no hook error
