## New

- **Backlog triage skill** - The new `backlog-triage` skill turns the open backlog into a private decision page: the owner picks close, rewrite, leave or prioritise for each issue, and the skill applies those choices. ([#880](https://github.com/cbundy/dev-system/pull/880))
- **Factory database reads in dev-query** - `dev-query --factory` reads the factory event log as the read-only reader role. A shared source switch lets a factory read tool answer from the old store while it records how the new one differed, logged as a `shadow_read` event with a saved query (metrics 6b). ([#908](https://github.com/cbundy/dev-system/pull/908), [#907](https://github.com/cbundy/dev-system/pull/907))

## Fixed

- **Park questions keep their options** - A parked issue's comment keeps the question's line breaks, so its options render and ticking one resumes the issue again. ([#861](https://github.com/cbundy/dev-system/pull/861))
- **A reopened issue no longer holds releases** - When a merged issue reopens, the v2 loop moves it off `Next release` to `Later` and tells the owner, so the release review can start. ([#881](https://github.com/cbundy/dev-system/pull/881))
- **Steadier factory-loop tests** - Tests that drive the loop engine get a 30 s budget, so they no longer fail on a busy machine. ([#882](https://github.com/cbundy/dev-system/pull/882))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.44.0.
- Factory database: after the restart `dev-doctor` reports the factory database as behind until `factory-db-bootstrap --db <name>` is re-run with the admin URL (migration 0005).
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
