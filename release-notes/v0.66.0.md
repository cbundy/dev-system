## New

- **Designer model routing** - New `callum-flow-designer-route <issue>` picks the designer's model (a `model:` label wins, otherwise a configurable share goes to Sonnet via `CALLUM_FLOW_DESIGNER_SONNET_PCT`) and logs each choice as a `designer_routed` event, ready for comparing designer models. Nothing calls it yet (migration 0017). ([#1097](https://github.com/cbundy/dev-system/pull/1097))
- **Parked questions keep their parts** - A park whose question an agent structured now records its decision, context, options, recommended option and recommendation on the `transition` event and in `factory.event_log` (migration 0018). ([#1098](https://github.com/cbundy/dev-system/pull/1098))

## Changed

- **Permission prompts are native events** - The loop companion writes `prompt_denied` and `prompt_waiting` as native events with branch and PR, and the old-log translator now maps older lines of both kinds instead of skipping them. ([#1096](https://github.com/cbundy/dev-system/pull/1096))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.54.0. A loop workspace with the migrator secret applies migrations 0017 and 0018 itself at start-up.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update` (adds `callum-flow-designer-route` to the allow list).
