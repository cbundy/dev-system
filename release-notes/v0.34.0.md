## New

- **Workers report a heartbeat to the fleet** - Each workspace now reports regularly whether it is busy or idle to the shared factory database, so the fleet's live status view knows which workers are alive. `dev-doctor` shows the last beat and fails when a database is configured but the heartbeat is not running. ([#504](https://github.com/cbundy/dev-system/pull/504))
- **Image version is set at release time** - Feature PRs no longer bump the base image version, which removes a common cause of merge conflicts between open PRs. The release bump sets it instead, with strict version checking. ([#503](https://github.com/cbundy/dev-system/pull/503))

## Fixed

- **Tests no longer touch real workspace data** - `npm test` now runs in a sandbox, so a test can no longer write to your real pipeline, event or metrics state. ([#502](https://github.com/cbundy/dev-system/pull/502))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image (2.29.0): rebuild or re-pull the dev container to get the heartbeat loop.

## Verify

- After restarting onto base image 2.29.0, run `dev-doctor` and confirm the worker heartbeat line shows a recent beat.
- Confirm this workspace appears as alive in the factory's worker status view.
- Run `npm test` and confirm nothing under `~/.no-mistakes` or the events directory changes.
