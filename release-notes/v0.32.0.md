## New

- **Broad process kills are refused** - A new guard hook stops agents from killing processes by name or pattern (`pkill`, `killall`, `kill $(pgrep ...)`, `pgrep ... | xargs kill`). These are shared hosts, so one broad kill could stop the orchestrator's watchers or other agents' work. Kills scoped to the agent's own worktree or scratchpad, or to its own child processes, still work ([#460](https://github.com/cbundy/dev-system/pull/460))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- In a session, `pkill -f some-pattern` is refused with the forbid-broad-kill message
- `kill "$pid"` on a recorded PID still works
