## New

- **Merge and PR metrics** - docs/metrics.md gains section 9c: merges per day, PR open-to-merge time, PRs per issue, head moves and the longest merge gaps, plus judge task outcomes in section 9. `callum-flow-evaluate` reports the same merges, PRs and gaps, and `merged.recovered` becomes a `factory.event_log` column (migration 0021). ([#1144](https://github.com/cbundy/dev-system/pull/1144))
- **Container memory pressure is recorded** - Each heartbeat stores the container's memory-limit events, OOM kills and memory pressure (migration 0020), and dev-doctor shows one memory line that warns when the workspace is short of memory. ([#1137](https://github.com/cbundy/dev-system/pull/1137))

## Changed

- **The claim queue is ordered by a score** - After the owner's only and priority lists, the loop claims issues by a score of named factors (priority label, bug, unblocks, closes or nearly closes an epic, waiting time, failed lives) instead of the lowest number. Weights are set with `/factory config set queueScore.<name> N`, and each claim records its score. ([#1139](https://github.com/cbundy/dev-system/pull/1139))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.56.0. A loop workspace with the migrator secret applies migrations 0020 and 0021 itself at start-up.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
