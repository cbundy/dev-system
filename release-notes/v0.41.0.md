## New

- **Remote Control sessions come back after a restart** - After a workspace restart or rebuild, every Remote Control session that was live comes back online in claude.ai as the same session, with its history and permission mode, and waits for you. Sessions started by a `server` mode workspace are reattached to their own claude.ai session. ([#599](https://github.com/cbundy/dev-system/pull/599))
- **Shared or private Claude login per workspace** - Each Coder workspace can share one Claude login with other workspaces or keep its own, with history and settings always per workspace. Private stays the default, so existing workspaces are unchanged. ([#679](https://github.com/cbundy/dev-system/pull/679), [#682](https://github.com/cbundy/dev-system/pull/682))
- **Shared or private GitHub login per workspace** - Each Coder workspace can now keep its own GitHub CLI login instead of the shared one, which stays the default. ([#692](https://github.com/cbundy/dev-system/pull/692))

## Changed

- **Spike notes live in the repo** - The synced `CLAUDE.md` now asks for a spike's notes, probe code and evidence under `docs/spikes/<topic>/`, with its conclusions carried into the lasting docs. ([#677](https://github.com/cbundy/dev-system/pull/677))

## Fixed

- **Idle loop workers no longer show as busy** - The v2 factory loop's bookkeeping events no longer count as work in the heartbeat. ([#690](https://github.com/cbundy/dev-system/pull/690))

## Upgrade

- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image: rebuild or re-pull the dev container. On Coder, restart the workspace to pick up the new image and choose its Claude and GitHub login after a template update.

## Verify

- Start a Remote Control session on a `server` mode workspace, restart the workspace, and confirm the session comes back online as the same claude.ai session with its history.
- Confirm `tmux ls` shows `rc-restored` after that restart and the restored session was sent no message.
- Confirm a workspace set to a shared Claude login is signed in after a second shared workspace signs in.
- Confirm a workspace left on the defaults keeps its own Claude login and the shared GitHub login.
