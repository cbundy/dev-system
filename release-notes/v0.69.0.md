## Changed

- **The factory loop reads events from the new database by default** - With no `eventsSource` setting, the loop now rebuilds records, facts, the 7-day ledger and once keys from the factory database (`factory.event_store`) alone, instead of running both sources in shadow. Run `/factory config set eventsSource old` to go back; `shadow` stays available as an opt-in. ([#1015](https://github.com/cbundy/dev-system/pull/1015))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- With no `eventsSource` setting, confirm `/factory config` shows `eventsSource` as `new` and the loop's records and facts rebuild without errors.
- Confirm no new `shadow_read` events are written under the default.
- Set `eventsSource old`, confirm the next pass reads the old source, then clear the setting again.
