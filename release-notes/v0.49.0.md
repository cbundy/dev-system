## New

- **A workspace can log in to GitHub with its own token** - The Coder template gains a `token` choice for the GitHub login, backed by a per-workspace secrets folder. In token mode, `dev-doctor` checks what the token can reach (scopes for a classic token, permissions for a fine-grained one) and fails naming each missing one. ([#763](https://github.com/cbundy/dev-system/pull/763), [#762](https://github.com/cbundy/dev-system/pull/762))
- **Check that dual write holds** - `callum-flow-dual-write-check` compares the old and new factory event stores read-only and reports any event missing or different in the new one. ([#760](https://github.com/cbundy/dev-system/pull/760))
- **Heartbeats reach the factory database** - Each workspace's heartbeat now also writes its worker row to the new factory database, as the writer role. ([#759](https://github.com/cbundy/dev-system/pull/759))

## Fixed

- **Split sub-issues no longer block the queue forever** - A sub-issue made by a split now closes when its PR merges, instead of staying open and holding every issue it blocks. The owner is told when a keep-open issue blocks others. ([#766](https://github.com/cbundy/dev-system/pull/766))
- **Releases no longer stop being proposed** - The loop now reviews for a release once an hour against the last tag, instead of a count that could repeat and silently never fire again. ([#769](https://github.com/cbundy/dev-system/pull/769))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.40.0.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Coder: push the templates from main (`coder/push.sh <template>`); set `workspace_secrets_dir` to offer the token login.

## Verify

- On a token-mode workspace, confirm `dev-doctor` passes with a token that has repo and workflow, and fails naming the missing one otherwise.
- Run `callum-flow-dual-write-check --since <an hour ago>` on a dual-writing workspace and confirm it reports no misses.
- Confirm the workspace's worker row appears in `factory.workers` in the factory database after a heartbeat.
- Merge a split sub-issue's PR and confirm the sub-issue closes and its dependants become claimable.
