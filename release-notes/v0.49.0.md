## New

- **The judge decides when to release, and a release agent ships it** - On the hourly release review the loop's judge now weighs whether a release is worth cutting, and a dedicated release agent runs the bump, release and image publish. A new `minimumReleaseCadence` setting (default 6h) sets the shortest gap between releases. ([#765](https://github.com/cbundy/dev-system/pull/765), [#786](https://github.com/cbundy/dev-system/pull/786))
- **Change loop settings from chat** - `/factory config set <key> <value>` and `/factory config unset <key>` edit the workspace settings file, refusing any value the loop would reject and leaving the file untouched. ([#770](https://github.com/cbundy/dev-system/pull/770))
- **A workspace can log in to GitHub with its own token** - The Coder template gains a `token` choice for the GitHub login, backed by a per-workspace secrets folder. In token mode, `dev-doctor` checks what the token can reach and fails naming each missing scope or permission. ([#763](https://github.com/cbundy/dev-system/pull/763), [#762](https://github.com/cbundy/dev-system/pull/762))
- **Check that dual write holds** - `callum-flow-dual-write-check` compares the old and new factory event stores read-only, and heartbeats now also write their worker row to the new factory database. ([#760](https://github.com/cbundy/dev-system/pull/760), [#759](https://github.com/cbundy/dev-system/pull/759))

## Changed

- **Splits explain themselves** - When the designer splits an issue, the plan comment now says why it split, why into that many parts and in that order, with a one-line reason per sub-issue. ([#785](https://github.com/cbundy/dev-system/pull/785))

## Fixed

- **Split sub-issues no longer block the queue forever** - A sub-issue made by a split now closes when its PR merges, instead of staying open and holding every issue it blocks. ([#766](https://github.com/cbundy/dev-system/pull/766))
- **Releases no longer stop being proposed** - The loop reviews for a release once an hour against the last tag, instead of a count that could repeat and never fire again. ([#769](https://github.com/cbundy/dev-system/pull/769))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.40.0.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Coder: push the templates from main (`coder/push.sh <template>`); set `workspace_secrets_dir` to offer the token login.
