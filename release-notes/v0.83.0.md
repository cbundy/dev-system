## New

- **Claude on an Anthropic API key** - A Coder workspace can now run Claude on its own API key: pick the new `api-key` option of the `claude_login` parameter (offered with `workspace_secrets_dir`) and put the key in `anthropic-api-key` in the workspace's secrets folder on the Docker host. The key never passes through Terraform, an env var or a log; Claude starts headless without Remote Control, and `dev-doctor` shows the auth mode. ([#1201](https://github.com/cbundy/dev-system/pull/1201))
- **Monthly dollar budget for the loop in API-key mode** - Two new template parameters, `claude_budget_usd` and `claude_budget_reset_day`, set a monthly spend budget. The loop tallies its session's cost against it and paces itself through the existing slow, stop-new and stop-all thresholds; a missing reading holds new work. `/factory config` shows the budget, and usage events carry the spend. ([#1202](https://github.com/cbundy/dev-system/pull/1202))

## Changed

- **Testbed regime in the health check** - `testbed-check.sh` prints the testbed loop's regime and warns when it is not `testbed`. ([#1199](https://github.com/cbundy/dev-system/pull/1199))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Base image: rebuild or re-pull the dev container to get API-key mode and the updated `usage-check.sh`.
- Coder template: the owner pushes the updated `dev-system` template to get the new `api-key` login option and budget parameters.

## Verify

- On a `dev-system-next` workspace with `workspace_secrets_dir`, confirm `claude_login` offers `api-key` and the budget parameters appear.
- With `api-key` and a key file present, confirm Claude starts headless in the `claude` tmux session without Remote Control, and `claude auth status` succeeds.
- With the key file missing, confirm `dev-remote-control` waits and prints its hint, and starts no Claude session.
- Confirm the key appears in no `ps` output, process environment or log.
- Run `dev-doctor` and confirm it shows the auth mode and checks the key file and helper.
- Set a small `claude_budget_usd` and confirm the loop's usage events report `source` spend with `spend_usd` and `budget_usd`, and `/factory config` shows the budget.
- Confirm a workspace without `DEV_CLAUDE_AUTH` keeps the claude.ai login and Remote Control unchanged.
