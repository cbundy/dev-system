## New
- **dev-version command** - reports whether the dev image, the plugin and the tools in a workspace are current, so stale environments are easy to spot ([#280](https://github.com/cbundy/dev-system/pull/280), [#282](https://github.com/cbundy/dev-system/pull/282)).
- **Pipeline data in PostgreSQL** - the base image mirrors no-mistakes pipeline runs into PostgreSQL and ships saved queries for them ([#279](https://github.com/cbundy/dev-system/pull/279), [#281](https://github.com/cbundy/dev-system/pull/281)).
- **Fleet-wide evaluation** - `evaluate-sessions` can read a fleet-wide no-mistakes export with `--nm-export` ([#285](https://github.com/cbundy/dev-system/pull/285)).

## Upgrade
- Plugin: run `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image: rebuild or re-pull the dev container to get `dev-version` and the PostgreSQL mirror.
