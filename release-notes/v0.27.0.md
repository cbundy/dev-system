## New

- **Release milestones** - Every PR and the issues it closes now land in a "Next release" milestone at merge, and each release renames it to the version and opens a fresh one, so what ships next and what each release contained are visible on GitHub. Past releases are backfilled ([#412](https://github.com/cbundy/dev-system/pull/412), [#414](https://github.com/cbundy/dev-system/pull/414))
- **Fresh worktrees start at the remote tip** - A new Claude Code worktree fetches and fast-forwards to the latest default branch before the first turn, instead of starting from a stale local copy ([#396](https://github.com/cbundy/dev-system/pull/396))
- **One combined orchestrator watcher** - `orchestrator-watch.sh` runs the queue and pipeline watchers as one process with a deadline and an exact re-arm line, the base for cutting idle orchestrator wake-ups ([#413](https://github.com/cbundy/dev-system/pull/413))
- **Versions on every factory event** - Events record the base image, dev image, template and plugin versions that produced them, and reach the database within seconds ([#401](https://github.com/cbundy/dev-system/pull/401))

## Changed

- **Plain-language status for the owner** - Agents now lead with what needs to happen next and who acts, and name work by what it does rather than by issue number ([#416](https://github.com/cbundy/dev-system/pull/416))
- **Replaced branches no longer look abandoned** - A replaced branch is logged as `superseded`, and the factory-state view keeps an issue live when work continues after an `abandoned` event ([#417](https://github.com/cbundy/dev-system/pull/417))
- **Hourly orchestrator audit** - The audit runs hourly instead of every 20 minutes, still well inside the claim lease ([#408](https://github.com/cbundy/dev-system/pull/408))
- **Epic sub-issues** - The shared instructions ask agents to link an epic's parts as GitHub sub-issues so progress shows in the UI ([#407](https://github.com/cbundy/dev-system/pull/407))

## Fixed

- **Heredoc false refusals** - The tmux-kill and git-stash guards no longer refuse harmless commands with a backtick or `$(` inside a quoted heredoc, and real kills next to a heredoc are still caught ([#409](https://github.com/cbundy/dev-system/pull/409))
- **Coder login hints** - On Coder, login and Remote Control hints say `coder ssh <workspace> -- <command>` instead of `docker exec` ([#410](https://github.com/cbundy/dev-system/pull/410))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image 2.27.0: rebuild or re-pull the dev container.
