## Fixed

- **Answered agents no longer stall the factory loop** - An agent that has given its answer but stays listed as working, usually because it left a background command running, is stopped one minute after answering and the owner is told once. It no longer holds up the main checkout update, the reviews queued behind it, or its own branch. ([#611](https://github.com/cbundy/dev-system/pull/611))
- **Loop recovers after catching a PR up with main** - After the loop rebases a PR that fell behind main, its merge checks now accept the rebased head instead of failing on it every time. Ship this plugin together with base image 2.32.1. ([#610](https://github.com/cbundy/dev-system/pull/610))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.32.1, together with the plugin update.
- Plugin, CLI and templates: `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.

## Verify

- Confirm a PR the loop brings up to date with main passes the next merge check and merges without a new pipeline run.
- Confirm an agent left running after its answer is stopped about a minute later and the owner gets one message about it.
