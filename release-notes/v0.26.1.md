## Fixed
- **Login checks no longer drain the GitHub API** - `dev-login` checks GitHub with a cached result (at most one API call per 15 minutes, none without a local token), its watcher backs off to 15 minutes and gives up on the `workflow` scope with one notification, codex is optional by default, and the Coder "Logins" row reads the cache every 5 minutes. Together these were exhausting the shared 5000/hour GitHub limit every hour ([#383](https://github.com/cbundy/dev-system/pull/383)).

## Upgrade
- Base image: rebuild or re-pull the dev container (Coder: restart the workspace).
- Coder template: the "Logins" row change ships in `coder/dev-system`; it takes effect once the template is pushed.
