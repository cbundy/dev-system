## New

- **Shadow compare for the loop's record rebuild** - A new `eventsSource` loop setting (`old`, `new`, `shadow`; default `shadow`) lets the loop rebuild its issue records from the new event store. In `shadow` it reads both stores at most hourly, compares them and tells the owner once per set of differing issues, while still running on the old records. ([#989](https://github.com/cbundy/dev-system/pull/989))
- **A fix that needs no new commit has its own result** - A fixer that fixes a finding outside the branch, such as the PR description or evidence, now answers `unchanged`, and the PR goes back to review instead of the answer being refused. ([#985](https://github.com/cbundy/dev-system/pull/985))

## Fixed

- **Design waits that can never clear are refused** - The answer script now checks each condition of a designer's wait on GitHub (the commit, release, issue or PR it names) and refuses one that cannot hold, naming what to fix. If GitHub cannot be read, the answer is recorded as before. ([#988](https://github.com/cbundy/dev-system/pull/988))
- **The final heartbeat is sent when a container stops** - On a docker stop or pod deletion, the image's entrypoint now forwards the signal to the command, waits for it to exit and sends the last heartbeat, so the container reads as stopped at the right time. ([#984](https://github.com/cbundy/dev-system/pull/984))

## Upgrade

- Base image: restart workspaces (or rebuild the dev container) onto base image 2.47.2.
- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Factory loop: the record rebuild now runs in `shadow` by default. If its tells get noisy or the new read misbehaves, go back with `/factory config set eventsSource old`.

- Confirm a shadow compare with differences tells the owner once per set of issues, naming the way back.
- Set `eventsSource` to an invalid value and confirm it is reported as a config problem and reads as `old`.
- Answer a design wait with a `tag-contains` condition on a repo without releases and confirm it is refused.
- Confirm a fixer answer of `unchanged` sends the PR back to review with the round increased.
- On base image 2.47.2, `docker stop` a container and confirm heartbeat-state shows it stopped with no later beat.
