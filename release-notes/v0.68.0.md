## New

- **A stop gate cut by a loop restart is re-run** - When a loop restart cuts a builder's or fixer's stop gate, the loop now re-runs that gate on its next beat instead of leaving the issue idle until the 45-minute hold times out. Each gate start, re-run and cut is logged. ([#1106](https://github.com/cbundy/dev-system/pull/1106))
- **Park questions keep their structure** - When the loop parks on a question, it now records the decision, context, options and recommendation on the record and its event, not only the rendered text. ([#1104](https://github.com/cbundy/dev-system/pull/1104))

## Fixed

- **No false shadow alarms from key order** - The records and facts shadow compares now ignore JSON object key order, so they stop raising `records-shadow` and `facts-shadow` tells for values that only differ in key order. ([#1107](https://github.com/cbundy/dev-system/pull/1107))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.

## Verify

- Restart a loop while a stop gate is running and confirm a `gate-rerun` line appears and the gate settles with `rerun: true`.
- Let the loop park on a designer question and confirm the record carries `parts`.
- Confirm the next records-shadow compare no longer lists key-order-only differences.
