## New

- **Factory HUD on every client** - A new opt-in `factory-hud` plugin keeps one line on screen with the time, context fill, 5-hour and 7-day plan usage, the orchestrator's factory counts and the tool versions. It shows in the terminal, the desktop app and the Claude mobile app through Remote Control, and toasts once when context or usage crosses its threshold. `/hud` hides or shows it ([#457](https://github.com/cbundy/dev-system/pull/457))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- Factory HUD: in the workspace's Claude session run `/plugin install factory-hud@callum` at user scope, or `claude plugin install factory-hud@callum --scope user` then `/reload-plugins`.

## Verify

- After installing, the orchestrator session shows the HUD line with live factory counts
- The same line shows when the session is opened on the phone through Remote Control
- `/hud` hides the line in that conversation and shows it again
