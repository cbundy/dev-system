## New

- **UI capture tool in the base image** - `callum-flow-capture` starts a repo's app on a free port, takes desktop and narrow full-page screenshots (and an optional video) with headless Chromium, stops the app on every exit and can upload the captures as PR evidence. The image ships the tool only; a UI repo adds Playwright and Chromium to its own dev image (see the base image README). ([#1285](https://github.com/cbundy/dev-system/pull/1285))
- **`uiCapture` repo setting** - Tells the factory loop how a repo captures UI evidence: a capture command the builder and fixer run first for a visible change, or `none` when the repo has no capture tooling, so the reviewer treats a missing capture as a warning at most. Unset keeps today's behavior. ([#1284](https://github.com/cbundy/dev-system/pull/1284))

## Changed

- **Plain summaries in briefs and park questions** - Design briefs and owner questions now open with a short plain summary, with the full technical text in a collapsed Details block. ([#1280](https://github.com/cbundy/dev-system/pull/1280))

## Fixed

- **Recovered merges keep their real merge time and title** - Merged events now carry GitHub's merge time and the issue or PR title, so hand merges recovered by the sweep no longer show as just merged and untitled. ([#1281](https://github.com/cbundy/dev-system/pull/1281))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A loop workspace on the `orchestrator-loop` template picks up the plugin only after that template is pushed at this release (`coder/push.sh orchestrator-loop`).
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update` (adds the `callum-flow-capture` allow entry).
- Base image: rebuild or re-pull the dev container to get image 2.72.0 (`callum-flow-capture` and factory DB migration 0031). Loops apply the migration at their next start.
