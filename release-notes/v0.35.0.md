## New

- **Implementer model comparison** - The orchestrator now routes each implementation between Sonnet and Opus and records which model built it, so time and pipeline failures can be compared per model. ([#510](https://github.com/cbundy/dev-system/pull/510))
- **Re-gate a rebased branch in one step** - New `callum-flow-regate` helper re-runs the pipeline on a rebased branch under the same name and PR, refusing if the rebase dropped a commit. The merge guard and fixer now point to it. ([#516](https://github.com/cbundy/dev-system/pull/516))
- **Meaningful Coder template version names** - Template pushes are named after the git commit and push time (for example `v0.35.0-20261012-201500`) instead of random words. ([#517](https://github.com/cbundy/dev-system/pull/517))
- **Local PostgreSQL in this repo's dev image** - Metrics SQL can be checked against a real Postgres 17 without Docker. ([#512](https://github.com/cbundy/dev-system/pull/512))

## Changed

- **Shorter, linked orchestrator updates** - Routine updates are one status line, and every issue or PR reference is a link with a few words saying what the work is. The owner-writing rule in `CLAUDE.md` now asks for the same. ([#518](https://github.com/cbundy/dev-system/pull/518))

## Fixed

- **Dev-version test no longer flakes on a busy host** - The timing check is replaced by one that does not depend on machine load. ([#513](https://github.com/cbundy/dev-system/pull/513))

## Upgrade

- Plugin: run `npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`. A plain `/plugin marketplace update` does not advance the pinned ref.
- CLI and templates: `npm update @callum/dev-system && npx callum-dev update`.
- Base image (2.30.0): rebuild or re-pull the dev container to get `callum-flow-regate` and the implementer routing helper.
