## Changed

- **Old event log retired** - `callum-flow-event` now writes only the new factory event, so no new rows reach the old event log or `factory.events`. A write it cannot translate is skipped with one warning instead of failing. `dev-init` no longer starts the old event push, and `dev-doctor` and the heartbeat no longer report it missing. ([#1179](https://github.com/cbundy/dev-system/pull/1179))

## Upgrade

- Base image: rebuild or re-pull the dev container to get the updated factory tools.

## Verify

- Claim an issue and confirm a `claimed` event lands in the new event store and nothing new lands in the old log or `factory.events`.
- Confirm `dev-init` no longer starts `event-push-loop` and `dev-doctor` passes without it.
- Confirm the heartbeat no longer reports `events_push_not_running`.
- Run `callum-flow-factory-state` and confirm claims, merges and sweeps still show as before.
- Let queue-watch run and confirm an unchanged issue writes no new event, while a title or label change does.
