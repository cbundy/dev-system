## New

- **Foreman skill** - The factory-loop plugin's `foreman` skill gives a session the role of supervising a repo's v2 loop from outside: regular checks, filing bugs with evidence, and stepping in only where the loop cannot help itself. ([#669](https://github.com/cbundy/dev-system/pull/669))

## Fixed

- **Template pushes keep private-image credentials** - Every Coder template push now keeps the registry credentials path, so a workspace on a private per-repo image (such as `plant-console/dev`) starts after a push. ([#643](https://github.com/cbundy/dev-system/pull/643))

## Upgrade

- Plugin, CLI and templates: `npm update @callum/dev-system && npx callum-dev update`, commit the `.claude/settings.json` it produces, then restart the container or run `dev-init --plugins`.

## Verify

- Confirm `/factory-loop:foreman` is listed in a session after the plugin update.
